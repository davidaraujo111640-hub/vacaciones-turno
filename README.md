# Vacaciones del Turno

Calendario para que los compañeros del turno pidan y retiren días (vacaciones, AP, Navidad, Semana Santa u otro).

- Cuadrante: 6 tardes · 6 libres · 6 mañanas · 6 libres, desde el 5 de noviembre de 2026.
- App web instalable en el móvil (PWA), alojada en GitHub Pages.
- Datos compartidos en Firebase Firestore (proyecto `vacaciones-del-turno`). Las reglas de seguridad están en `firestore.rules`.

## Cambiar la lista de compañeros

Edita la lista `people = [...]` al final de `index.html` y sube el cambio.
