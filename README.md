# Vacaciones del Turno

Calendario para que los compañeros del turno pidan y retiren días (vacaciones, AP, Navidad, Semana Santa u otro).

- Cuadrante: 6 tardes · 6 libres · 6 mañanas · 6 libres, desde el 5 de noviembre de 2026.
- Compañeros: Lara, Udyki, Jaime, Juanjo, Carmen, Laura, Soledad, Jorge, Valdi, Antonio, Guillermo y Álvaro.

## Nota sobre los datos

Los datos compartidos (compañeros, días pedidos e historial) se guardan con la base de datos de los Artifacts de Claude, así que solo funcionan dentro de la versión publicada en claude.ai:
https://claude.ai/artifact/EWDxF8iHV8UwG2hxj48H3b

Abierto fuera de Claude (por ejemplo, en GitHub Pages) se ve el calendario con el cuadrante, pero no se cargan ni se guardan peticiones.
